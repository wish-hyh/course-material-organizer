# Course Material Organizer（课程资料整理工具）

一个计划使用 Python 开发的课程资料整理工具，旨在帮助学生按照课程名称和日期对学习资料进行分类管理，让课程文件更加清晰、有序，方便后续查找和使用。

## 1. 项目简介

在日常学习过程中，课程课件、实验报告、课堂笔记和参考资料通常分散在不同文件夹中，容易出现文件混乱、查找困难等问题。

Course Material Organizer 希望通过简单的命令行操作，帮助用户按照课程名称和日期整理学习资料，提高学习资料管理的效率。

**当前项目状态：** 本项目目前处于设计与规划阶段，尚未完成具体功能开发，暂时没有可供安装和运行的正式版本。

## 2. 计划实现的功能

项目后续计划实现以下功能：

- 按照课程名称对学习资料进行分类。
- 根据日期整理课程相关文件。
- 支持查看和管理已有的课程资料。
- 提供简单易用的命令行操作方式。

以上为项目规划，具体功能将在后续开发过程中逐步实现。
